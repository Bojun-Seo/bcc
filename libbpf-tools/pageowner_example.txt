Demonstrations of pageowner, the Linux BPF CO-RE version.


pageowner shows who allocated the pages that are still allocated, like the
page_owner feature of the kernel (CONFIG_PAGE_OWNER). It records the kernel
stack trace, task, gfp mask, order and time of each page allocation, drops the
record when the pages are freed, and summarizes the remaining, outstanding,
pages by stack trace. page_owner needs a kernel built with CONFIG_PAGE_OWNER
and booted with page_owner=on, which production systems rarely are. pageowner
works on a running kernel without a reboot, but only sees the pages allocated
after it started.

This helps when memory goes somewhere that the RSS of processes does not
explain: kernel memory allocated directly from the page allocator. For
example, a process filled 100 pipes that nobody reads, so the kernel keeps the
data in the buffers of the pipes:

the last line counts all outstanding pages.

-d prints each outstanding allocation in the format of
/sys/kernel/debug/page_owner instead, ordered by PFN, with the task and the gfp
mask. Here for the pipes of a process, PID 3217:

# ./pageowner -p 3217 -d
Tracing page allocations... Hit Ctrl-C to end.
^C
[...]

The names of the gfp flags are shown on Linux 6.9 and later; older kernels
show the mask only. As only the dump is written to stdout, it can be saved and
post-processed by tools that read page_owner output, e.g. sorted by memory
with page_owner_sort from tools/mm of the kernel source:

# ./pageowner -d > page_owner_full.txt
# ./page_owner_sort -m page_owner_full.txt sorted_page_owner.txt


USAGE message:

# ./pageowner --help
Usage: pageowner [OPTION...]
Show the owners of outstanding page allocations, like page_owner.

USAGE: pageowner [-h] [-v] [-p PID] [-T TOP] [-d] [interval] [count]

EXAMPLES:
    pageowner            # summarize outstanding pages by stack on Ctrl-C
    pageowner 5 3        # summarize every 5 seconds, 3 times
    pageowner -p 181     # only track pages allocated by PID 181
    pageowner -T 3       # show the top 3 stacks only
    pageowner -d         # dump each allocation in page_owner format

  -d, --dump                 Dump each outstanding allocation like
                             /sys/kernel/debug/page_owner
      --max-allocs=MAX-ALLOCS   the number of outstanding allocations that can
                             be tracked (default 1048576, or the number of
                             pages in the system if smaller)
      --perf-max-stack-depth=PERF-MAX-STACK-DEPTH
                             the limit for kernel stack traces (default 127)
  -p, --pid=PID              Only track pages allocated by this process
      --stack-storage-size=STACK-STORAGE-SIZE
                             the number of unique stack traces that can be
                             stored and displayed (default 10240)
  -T, --top=TOP              Show only this many top stacks (default 10)
  -v, --verbose              Verbose debug output
  -?, --help                 Give this help list
      --usage                Give a short usage message
  -V, --version              Print program version

Mandatory or optional arguments to long options are also mandatory or optional
for any corresponding short options.
